BUG-DOC-001: Файл не удаляется из S3 при удалении документа

| Поле | Значение |
|------|----------|
| ID | BUG-DOC-001 |
| Дата | 19 октября 2025 |
| Severity | Medium |
| Priority | P2 |
| Статус | Fixed |

Описание

При удалении документа через API запись удаляется из БД, но файл остается в S3.

Шаги воспроизведения

1. Загрузить документ
2. Удалить через DELETE /documents/{id}
3. Проверить S3 bucket
4. Файл все еще существует

Влияние

- Накопление ненужных файлов в хранилище
- Дополнительные расходы на хранение

Исправление

| Дата | Действие |
|------|----------|
| 20 октября 2025 | Добавлен вызов S3 deleteObject |

BUG-DOC-002: Presigned URL работает дольше указанного времени

| Поле | Значение |
|------|----------|
| ID | BUG-DOC-002 |
| Дата | 20 октября 2025 |
| Severity | Low |
| Priority | P3 |
| Статус | Fixed |

Описание

Временный URL должен истекать через 15 минут, но работает до 30 минут.

Причина

Неправильное значение expiresIn (1800 вместо 900 секунд)

Исправление

| Дата | Действие |
|------|----------|
| 21 октября 2025 | Исправлено значение на 900 секунд |

BUG-DOC-003: Можно загрузить документ с MIME type text/html

| Поле | Значение |
|------|----------|
| ID | BUG-DOC-003 |
| Дата | 21 октября 2025 |
| Severity | Medium |
| Priority | P2 |
| Статус | Fixed |

Описание

Валидация проверяет только расширение файла, но не MIME type. Можно загрузить HTML файл с расширением .jpg.

Влияние

Потенциальная уязвимость XSS при открытии документа

Исправление

| Дата | Действие |
|------|----------|
| 22 октября 2025 | Добавлена проверка magic bytes файла |

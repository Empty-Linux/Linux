Описание сервиса

Document Service отвечает за загрузку, хранение и верификацию документов водителей.

Основные функции:
- Загрузка документов (водительские права, паспорт, СТС)
- Хранение в S3-совместимом хранилище
- Генерация временных URL для просмотра
- Верификация документов администратором
- История изменений документов

Типы документов:
- driver_license - водительское удостоверение
- passport - паспорт
- vehicle_registration - СТС автомобиля
- vehicle_insurance - страховка
- medical_certificate - медицинская справка

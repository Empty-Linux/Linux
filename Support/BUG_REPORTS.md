BUG-SUP-001: Можно отправить сообщение в закрытый тикет

| Поле | Значение |
|------|----------|
| ID | BUG-SUP-001 |
| Дата | 24 августа 2025 |
| Severity | Medium |
| Priority | P2 |
| Статус | Fixed |

Описание

После закрытия тикета пользователь все еще может отправлять сообщения.

Шаги воспроизведения

1. Закрыть тикет PUT /tickets/{id}/close
2. Отправить сообщение POST /tickets/{id}/messages
3. Сообщение успешно создается

Ожидаемый результат

400 Bad Request "Ticket is closed"

Исправление

| Дата | Действие |
|------|----------|
| 4 сентября 2025 | Добавлена проверка статуса перед созданием сообщения |

BUG-SUP-002: Уведомление не отправляется при ответе оператора

| Поле | Значение |
|------|----------|
| ID | BUG-SUP-002 |
| Дата | 27 августа 2025 |
| Severity | Medium |
| Priority | P2 |
| Статус | Fixed |

Описание

Когда оператор отвечает на тикет, пользователь не получает push-уведомление.

Шаги воспроизведения

1. Пользователь создает тикет
2. Оператор отвечает
3. Пользователь не получает push

Ожидаемый результат

Push notification с текстом ответа

Причина

Не был подключен Notification Service при ответе оператора

Исправление

| Дата | Действие |
|------|----------|
| 08 сентябрь 2025 | Добавлена отправка уведомления |

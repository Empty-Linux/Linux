Описание сервиса

Support Service отвечает за работу со обращениями пользователей.

Основные функции:
- Создание тикетов поддержки
- Чат с поддержкой
- Категоризация обращений
- Назначение операторам
- История обращений

Категории тикетов:
- payment - проблемы с оплатой
- order - проблемы с заказом
- driver - жалобы на водителя
- app - проблемы с приложением
- other - прочее

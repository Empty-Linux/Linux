Описание сервиса

Location Service отвечает за отслеживание геолокации водителей в реальном времени с использованием Redis Geospatial.

Основные функции:
- Обновление позиции водителя
- Поиск ближайших водителей
- Хранение истории локаций
- Расчет расстояния между точками

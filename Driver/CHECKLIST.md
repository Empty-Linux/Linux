Чек-лист тестирования Driver Service

Сервис: Driver Service
Версия: 1.0
Дата: 16-20 октября 2025

---

Описание

Чек-лист для функционального тестирования API сервиса управления водителями.

---

Эндпоинты

| Метод | Endpoint | Описание |
|-------|----------|----------|
| GET | /profile | Получение профиля водителя |
| PUT | /profile | Обновление профиля |
| POST | /online | Переход в онлайн |
| POST | /offline | Переход в офлайн |
| GET | /balance | Получение баланса |
| GET | /statistics | Статистика поездок |
| GET | /orders | История заказов |
| GET | /orders/{id} | Детали заказа |
| POST | /orders/{id}/accept | Принятие заказа |
| POST | /orders/{id}/reject | Отклонение заказа |
| GET | /documents | Список документов |
| POST | /documents | Загрузка документа |

TC-PSG-002: Добавление домашнего адреса

| Поле | Значение |
|------|----------|
| ID | TC-PSG-002 |
| Приоритет | High |
| Тип | Позитивный |
| Дата | 11 декабрь 2025 |

Предусловия
- Пассажир авторизован
- У пассажира нет сохраненного адреса "Дом"

Тестовые данные
```
Метод: POST
Endpoint: /addresses
Body:
{
  "name": "Дом",
  "address": "Площадь 1905 года",
  "latitude": 56.5098,
  "longitude": 60.3670
}
```

Шаги выполнения

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Отправить POST запрос | 201 Created |
| 2 | Проверить addressId в ответе | ID присутствует |
| 3 | Запросить список адресов | Новый адрес в списке |

Результат: Passed

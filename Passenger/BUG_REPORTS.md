BUG-PSG-001: Можно добавить более 10 адресов

Информация

| Поле | Значение |
|------|----------|
| ID | BUG-PSG-001 |
| Дата обнаружения | 1 декабрь 2025 |
| Severity | Low |
| Priority | P3 |
| Статус | Fixed |

Описание

Ограничение на максимальное количество сохраненных адресов (10) не работает.

Шаги воспроизведения

1. Добавить 10 адресов через POST /addresses
2. Попытаться добавить 11-й адрес
3. Адрес успешно добавляется

Ожидаемый результат

400 Bad Request с сообщением "Maximum addresses limit reached (10)"

Фактический результат

201 Created, адрес добавлен

Исправление

| Дата | Действие |
|------|----------|
| 3 декабрь 2025 | Добавлена проверка количества адресов |
| 4 декабрь 2025 | Верификация - ограничение работает |

BUG-PSG-002: Дубликаты промокодов не проверяются

Информация

| Поле | Значение |
|------|----------|
| ID | BUG-PSG-002 |
| Дата обнаружения | 3 декабрь 2025 |
| Severity | Medium |
| Priority | P2 |
| Статус | Fixed |

Описание

Пассажир может применить один и тот же промокод несколько раз.

Шаги воспроизведения

1. Применить промокод POST /promo с кодом DISCOUNT10
2. Получить 200 OK
3. Применить тот же промокод снова
4. Получить 200 OK снова

Ожидаемый результат

Второй запрос: 400 Bad Request "Promo code already used"

Фактический результат

200 OK, скидка применяется повторно

Исправление

| Дата | Действие |
|------|----------|
| 6 декабрь 2025 | Добавлена таблица использованных промокодов |
| 6 декабрь 2025 | Верификация - дубликаты отклоняются |

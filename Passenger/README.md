Описание сервиса

Passenger Service отвечает за управление профилями пассажиров, их адресами и платежными методами.

Основные функции:
- Получение и обновление профиля пассажира
- Управление сохраненными адресами
- Управление привязанными картами
- История поездок
- Применение промокодов

BUG-PRK-001: driversCount не обновляется при удалении водителя

| Поле | Значение |
|------|----------|
| ID | BUG-PRK-001 |
| Дата | 22 октября 2025 |
| Severity | Medium |
| Priority | P2 |
| Статус | Fixed |

Описание

При удалении водителя из парка счетчик driversCount не уменьшается.

Шаги воспроизведения

1. Парк с 10 водителями, driversCount = 10
2. Удалить одного водителя
3. driversCount = 10 (не изменился)

Ожидаемый результат

driversCount = 9

Исправление

| Дата | Действие |
|------|----------|
| 23 октября 2025 | Добавлен декремент счетчика при удалении |

BUG-PRK-002: Комиссия применяется к уже начатым заказам

| Поле | Значение |
|------|----------|
| ID | BUG-PRK-002 |
| Дата | 24 октября 2025 |
| Severity | High |
| Priority | P1 |
| Статус | Fixed |

Описание

При изменении комиссии парка новое значение применяется к заказам в статусе in_progress.

Шаги воспроизведения

1. Заказ в процессе, комиссия 15%
2. Изменить комиссию парка на 20%
3. Завершить заказ
4. Комиссия рассчитана как 20%

Ожидаемый результат

Для заказов in_progress должна применяться комиссия на момент создания заказа

Исправление

| Дата | Действие |
|------|----------|
| 25 октября 2025 | Комиссия сохраняется в заказе при создании |

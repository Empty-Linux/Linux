TC-ORD-001: Создание заказа

| Поле | Значение |
|------|----------|
| ID | TC-ORD-001 |
| Приоритет | Critical |
| Тип | Позитивный |
| Дата | 16 октября 2025 |

Предусловия
- Пассажир авторизован
- Координаты в зоне обслуживания

Тестовые данные
```
Метод: POST
Endpoint: /orders
Body:
{
  "pickupAddress": "Адрес отправления",
  "pickupLat": 56.5098,
  "pickupLng": 60.3670,
  "dropoffAddress": "Адрес назначения",
  "dropoffLat": 56.7133,
  "dropoffLng": 60.8249,
  "tariffId": "standard",
  "paymentMethod": "cash"
}
```

Шаги выполнения

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Отправить POST запрос | 201 Created |
| 2 | Проверить orderId | UUID присутствует |
| 3 | Проверить статус | pending |
| 4 | Проверить estimatedPrice | Числовое значение |
| 5 | Проверить Kafka | Событие order.created |

Результат: Passed

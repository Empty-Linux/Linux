BUG-ORD-001: Race condition при принятии заказа

Информация

| Поле | Значение |
|------|----------|
| ID | BUG-ORD-001 |
| Дата обнаружения | 17 октября 2025 |
| Severity | Critical |
| Priority | P1 |
| Статус | Fixed |

Описание

При одновременных запросах от двух водителей оба могут принять один заказ.

Шаги воспроизведения

1. Создать заказ
2. Одновременно отправить accept от водителя A и B
3. Оба запроса возвращают 200 OK
4. Заказ назначен последнему

Ожидаемый результат

Второй запрос должен вернуть 409 Conflict

Фактический результат

Оба 200 OK, заказ перезаписывается

Причина

Отсутствует блокировка на уровне БД при обновлении.

Исправление

| Дата | Действие |
|------|----------|
| 18 октября 2025 | Добавлена оптимистичная блокировка (version) |
| 19 октября 2025 | Верификация - второй получает 409 |

BUG-ORD-002: Можно создать заказ с pickup = dropoff

Информация

| Поле | Значение |
|------|----------|
| ID | BUG-ORD-002 |
| Дата обнаружения | 16 октября 2025 |
| Severity | Medium |
| Priority | P2 |
| Статус | Fixed |

Описание

Система позволяет создать заказ с одинаковыми координатами отправления и назначения.

Шаги воспроизведения

1. POST /orders с pickupLat = dropoffLat и pickupLng = dropoffLng
2. Заказ создается успешно
3. Цена рассчитывается как 0 или минимальная

Ожидаемый результат

400 Bad Request "Pickup and dropoff cannot be the same"

Исправление

| Дата | Действие |
|------|----------|
| 17 октября 2025 | Добавлена проверка расстояния > 100м |
| 18 октября 2025 | Верификация |

BUG-ORD-003: Статус заказа не обновляется в кеше

Информация

| Поле | Значение |
|------|----------|
| ID | BUG-ORD-003 |
| Дата обнаружения | 19 октября 2025 |
| Severity | Medium |
| Priority | P2 |
| Статус | Fixed |

Описание

При изменении статуса заказа кеш Redis не инвалидируется, и GET /orders/{id} возвращает старый статус.

Шаги воспроизведения

1. Получить заказ GET /orders/{id} (закешируется)
2. Изменить статус PUT /orders/{id}/status
3. Получить заказ снова
4. Статус старый (из кеша)

Ожидаемый результат

Актуальный статус

Исправление

| Дата | Действие |
|------|----------|
| 20 октября 2025 | Добавлена инвалидация кеша при изменении |

BUG-ORD-004: Kafka событие не публикуется при отмене

Информация

| Поле | Значение |
|------|----------|
| ID | BUG-ORD-004 |
| Дата обнаружения | 20 октября 2025 |
| Severity | High |
| Priority | P1 |
| Статус | Fixed |

Описание

При отмене заказа пассажиром событие order.cancelled не публикуется в Kafka.

Шаги воспроизведения

1. Создать заказ
2. Отменить заказ POST /orders/{id}/cancel
3. Проверить Kafka UI
4. Событие order.cancelled отсутствует

Влияние

- Sync Service не получает обновление
- Водитель не получает уведомление
- Статистика не обновляется

Исправление

| Дата | Действие |
|------|----------|
| 21 октября 2025 | Добавлена публикация события |

BUG-ORD-005: Оценка можно выставить дважды

Информация

| Поле | Значение |
|------|----------|
| ID | BUG-ORD-005 |
| Дата обнаружения | 21 октября 2025 |
| Severity | Low |
| Priority | P3 |
| Статус | Fixed |

Описание

Пассажир может выставить оценку одному заказу несколько раз.

Шаги воспроизведения

1. POST /orders/{id}/rate с rating: 5
2. POST /orders/{id}/rate с rating: 1
3. Оба запроса успешны
4. Рейтинг водителя некорректно изменяется

Ожидаемый результат

Второй запрос: 400 Bad Request "Order already rated"

Исправление

| Дата | Действие |
|------|----------|
| 22 октября 2025 | Добавлена проверка наличия оценки |

Описание сервиса

Order Service отвечает за управление жизненным циклом заказов такси.

Основные функции:
- Создание заказов
- Обновление статусов заказов
- Отмена заказов
- История заказов
- Интеграция с Kafka для событий

Статусы заказа:
pending - searching - accepted - arrived - in_progress - completed
                                                        - cancelled

BUG-ADM-001: park_admin может видеть водителей других парков

| Поле | Значение |
|------|----------|
| ID | BUG-ADM-001 |
| Дата | 27 октября 2025 |
| Severity | High |
| Priority | P1 |
| Статус | Fixed |

Описание

park_admin может получить данные водителя из другого парка напрямую по ID.

Шаги воспроизведения

1. Авторизоваться как park_admin парка A
2. GET /admin/drivers/{driver_id_from_park_B}
3. Получаем 200 OK с данными чужого водителя

Ожидаемый результат

403 Forbidden или 404 Not Found

Исправление

| Дата | Действие |
|------|----------|
| 28 октября 2025 | Добавлена проверка parkId в middleware |

BUG-ADM-002: Статистика не учитывает parkId для park_admin

| Поле | Значение |
|------|----------|
| ID | BUG-ADM-002 |
| Дата | 28 октября 2025 |
| Severity | Medium |
| Priority | P2 |
| Статус | Fixed |

Описание

park_admin видит общую статистику всех парков вместо только своего.

Ожидаемый результат

Статистика должна быть отфильтрована по parkId

Исправление

| Дата | Действие |
|------|----------|
| 29 октября 2025 | Добавлен фильтр по parkId в статистику |

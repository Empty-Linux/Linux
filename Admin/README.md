Описание сервиса

Admin Web Service предоставляет REST API для административной панели.

Основные функции:
- Управление водителями (верификация, блокировка)
- Управление заказами (просмотр, отмена)
- Управление тарифами
- Просмотр статистики
- Управление таксопарками

TC-ADM-001: Логин администратора

|------|----------|
| ID | TC-ADM-001 |
| Приоритет | Critical |
| Дата | 25 октября 2025 |

Тестовые данные
```

  "email": "admin@example.com",
  "password": "********"
}
```

| Шаг | Действие | Результат |

BUG-RTE-001: Некорректное время маршрута в пробках

| Поле | Значение |
|------|----------|
| ID | BUG-RTE-001 |
| Дата | 6 января 2026 |
| Severity | Medium |
| Priority | P2 |
| Статус | Fixed |

Описание

Время маршрута не учитывает текущие пробки, возвращается идеальное время.

Ожидаемый результат

duration должен учитывать traffic conditions

Исправление

| Дата | Действие |
|------|----------|
| 17 января 2026 | Добавлен параметр traffic=true в запрос к внешнему API |

BUG-RTE-002: Кеш не инвалидируется при изменении traffic

| Поле | Значение |
|------|----------|
| ID | BUG-RTE-002 |
| Дата | 7 января 2026 |
| Severity | Low |
| Priority | P3 |
| Статус | Open |

Описание

Закешированный маршрут возвращается с устаревшим временем, даже если пробки изменились.

Рекомендация

Уменьшить TTL кеша для маршрутов с учетом пробок до 5 минут.

Описание сервиса

Routing Service отвечает за построение маршрутов и геокодирование.

Основные функции:
- Построение маршрута между точками
- Геокодирование (адрес -> координаты)
- Обратное геокодирование (координаты -> адрес)
- Расчет расстояния и времени

Описание сервиса

Tariff Service отвечает за управление тарифами и расчет стоимости поездок.

Основные функции:
- CRUD операции с тарифами
- Расчет стоимости по тарифу
- Управление дополнительными услугами
- Surge pricing (повышенный спрос)

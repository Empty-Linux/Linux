TC-TRF-001: Расчет стоимости поездки

| Поле | Значение |
|------|----------|
| ID | TC-TRF-001 |
| Приоритет | Critical |
| Дата | 22 сентября 2025 |

Тестовые данные
```
POST /calculate
{
  "tariffId": "standard",
  "distance": 8500,
  "duration": 1200
}

Тариф standard:
- baseFare: 10
- perKm: 5
- perMin: 1
```

Ожидаемый расчет
```
baseFare + (distance/1000 * perKm) + (duration/60 * perMin)
10 + (8.5 * 5) + (20 * 1) = 10 + 42.5 + 20 = 72.5
```

Шаги

| Шаг | Действие | Результат |
|-----|----------|-----------|
| 1 | Отправить запрос | 200 OK |
| 2 | Проверить price | 72.5 |

Результат: Passed

TC-PRC-001: Базовый расчет стоимости

| Поле | Значение |
|------|----------|
| ID | TC-PRC-001 |
| Приоритет | Critical |
| Дата | октября 2025 |

Тестовые данные
```
POST /calculate
{
  "tariffId": "standard",
  "distance": 10000,
  "duration": 1800
}

Тариф:
baseFare: 10, perKm: 5, perMin: 1, minFare: 20
```

Ожидаемый расчет
```
baseFare + (distance/1000 * perKm) + (duration/60 * perMin)
10 + (10 * 5) + (30 * 1) = 10 + 50 + 30 = 90
```

Шаги

| Шаг | Действие | Результат |
|-----|----------|-----------|
| 1 | Отправить запрос | 200 OK |
| 2 | Проверить price | 90 |
| 3 | Проверить breakdown | baseFare, distanceFare, timeFare |

Результат: Passed

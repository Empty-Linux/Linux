BUG-PRC-001: Surge применяется после промокода

| Поле | Значение |
|------|----------|
| ID | BUG-PRC-001 |
| Дата | 19 октября 2025 |
| Severity | Medium |
| Priority | P2 |
| Статус | Fixed |

Описание

Порядок расчета неверный: промокод применяется до surge, что уменьшает эффект скидки.

Шаги воспроизведения

1. Базовая цена: 100
2. Промокод: -20 (фиксированная)
3. Surge: 1.5
4. Результат: (100 - 20) * 1.5 = 120

Ожидаемый результат

Правильный порядок: surge, затем промокод
(100 * 1.5) - 20 = 130

Исправление

| Дата | Действие |
|------|----------|
| 20 октября 2025 | Изменен порядок: surge -> extras -> promo |

BUG-PRC-002: Комиссия парка не учитывает промокод

| Поле | Значение |
|------|----------|
| ID | BUG-PRC-002 |
| Дата | 21 октября 2025 |
| Severity | High |
| Priority | P1 |
| Статус | Fixed |

Описание

Комиссия парка рассчитывается от полной цены, а не от цены после промокода.

Шаги воспроизведения

1. Цена: 100
2. Промокод: -20
3. Комиссия 15%: 100 * 0.15 = 15 (неверно)
4. Должно быть: 80 * 0.15 = 12

Влияние

Водитель получает меньше, чем должен

Исправление

| Дата | Действие |
|------|----------|
| 22 октября 2025 | Комиссия от finalPrice |

BUG-PRC-003: Surge не обновляется для редких зон

| Поле | Значение |
|------|----------|
| ID | BUG-PRC-003 |
| Дата | 22 октября 2025 |
| Severity | Low |
| Priority | P3 |
| Статус | Open |

Описание

Для зон с малым количеством заказов surge всегда 1.0, даже если все водители заняты.

Причина

Алгоритм surge требует минимум 10 заказов в час для расчета

Рекомендация

Добавить fallback на соотношение водителей/заказов

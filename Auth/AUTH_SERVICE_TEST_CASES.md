TC-AUTH-001: Успешная отправка SMS-кода

Общая информация

| Поле | Значение |
|------|----------|
| ID | TC-AUTH-001 |
| Название | Успешная отправка SMS-кода на валидный номер |
| Приоритет | High |
| Тип | Позитивный |
| Метод тестирования | Ручное (Postman) |

Предусловия

Сервис Auth Service запущен и доступен
SMS Gateway работает
Номер телефона валидный и может получать SMS

Тестовые данные

```
URL: POST /api/auth/send-code
Headers:
  Content-Type: application/json

Body:
{
  "phone": "+79001234567"
}
```

Шаги выполнения

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Открыть Postman | Postman открыт |
| 2 | Создать POST запрос на `/api/auth/send-code` | Запрос создан |
| 3 | Установить Header: `Content-Type: application/json` | Header установлен |
| 4 | В Body указать JSON с полем phone | Body заполнен |
| 5 | Нажать Send | Запрос отправлен |
| 6 | Проверить Status Code | 200 OK |
| 7 | Проверить тело ответа | JSON с полями success, message, expiresIn |

Ожидаемый результат

Status Code: 200 OK

Response Body:
```json
{
  "success": true,
  "message": "Verification code sent successfully",
  "expiresIn": 300
}
```

Дополнительно:
SMS с 6-значным кодом приходит на указанный номер
Код в ответе API НЕ возвращается (безопасность)
Время ответа < 3 секунд

Постусловия

Код сохранён в системе
Код имеет срок действия (5 минут)

Результат тестирования

| Поле | Значение |
|------|----------|
| Статус | PASSED ✅ |
| Дата | 2025-10-01 |
| Фактический результат | Соответствует ожидаемому |
| Время ответа | 1.2 сек |

TC-AUTH-003: Успешная верификация SMS-кода

Общая информация

| Поле | Значение |
|------|----------|
| ID | TC-AUTH-003 |
| Название | Успешная верификация с корректным кодом |
| Приоритет | Critical |
| Тип | Позитивный |
| Метод тестирования | Ручное (Postman) |

Предусловия

SMS-код был отправлен (TC-AUTH-001 выполнен)
Код не истёк (< 5 минут)
Код известен тестировщику

Тестовые данные

```
URL: POST /api/auth/verify
Headers:
  Content-Type: application/json

Body:
{
  "phone": "+79001234567",
  "code": "123456"
}
```

Шаги выполнения

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Выполнить TC-AUTH-001 (получить код) | Код получен |
| 2 | Отправить POST запрос на `/api/auth/verify` | Запрос отправлен |
| 3 | Указать phone и полученный code | Данные заполнены |
| 4 | Проверить Status Code | 200 OK |
| 5 | Проверить наличие accessToken | Присутствует |
| 6 | Проверить наличие refreshToken | Присутствует |
| 7 | Проверить данные пользователя | Присутствуют |
| 8 | Сохранить токены для следующих тестов | Токены сохранены |

Ожидаемый результат

Status Code: 200 OK

Response Body:
```json
{
  "success": true,
  "accessToken": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "refreshToken": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "user": {
    "id": "usr_abc123",
    "phone": "+79001234567",
    "role": "passenger",
    "createdAt": "2025-10-01T10:00:00Z"
  }
}
```

Проверки токена

accessToken должен быть валидный JWT (3 части через точку)
При декодировании payload содержит userId и exp
refreshToken отличается от accessToken

Постусловия

Пользователь авторизован
Код больше не может быть использован повторно
Токены можно использовать для других запросов

Результат тестирования

| Поле | Значение |
|------|----------|
| Статус | PASSED ✅ |
| Дата   | 2025-10-01 |
| Время ответа | 0.8 сек |

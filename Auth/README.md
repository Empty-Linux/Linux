О сервисе

Auth Service — сервис аутентификации пользователей через SMS-код.

Функции:
Отправка SMS-кода
Верификация кода
Выдача JWT токенов
Обновление токенов
Logout

Эндпоинты:
`POST /api/auth/send-code`
`POST /api/auth/verify`
`POST /api/auth/refresh`
`POST /api/auth/logout`
`GET /api/auth/me`

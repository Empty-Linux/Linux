Чек-лист тестирования Auth Service

Сервис: Auth Service (Сервис авторизации)
Версия: 1.0
Дата: October 2025

Описание сервиса

Auth Service отвечает за аутентификацию пользователей через SMS-код и управление JWT токенами.

Основные функции:
Отправка SMS-кода на телефон
Верификация SMS-кода
Выдача JWT токенов (access + refresh)
Обновление токенов
Выход из системы

Эндпоинты

| Метод | Endpoint | Описание |
|-------|----------|----------|
| POST | /api/auth/send-code | Отправка SMS-кода |
| POST | /api/auth/verify | Верификация кода |
| POST | /api/auth/refresh | Обновление токенов |
| POST | /api/auth/logout | Выход из системы |
| GET | /api/auth/me | Получение текущего пользователя |

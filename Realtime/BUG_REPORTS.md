BUG-RT-001: Соединение не закрывается при logout

| Поле | Значение |
|------|----------|
| ID | BUG-RT-001 |
| Дата | 22 Ноябрь 2025 |
| Severity | Medium |
| Priority | P2 |
| Статус | Fixed |

Описание

После logout через REST API WebSocket соединение остается активным.

Шаги воспроизведения

1. Подключиться к WebSocket
2. Выполнить POST /auth/logout
3. WebSocket соединение все еще активно
4. События продолжают приходить

Ожидаемый результат

Соединение должно закрыться с кодом 4002 (Session expired)

Исправление

| Дата | Действие |
|------|----------|
| 23 Ноябрь 2025 | Добавлена публикация события logout в Redis pub/sub |

BUG-RT-002: Дублирование событий при reconnect

| Поле | Значение |
|------|----------|
| ID | BUG-RT-002 |
| Дата | 23 Ноябрь 2025 |
| Severity | Medium |
| Priority | P2 |
| Статус | Fixed |

Описание

При переподключении клиент иногда получает события дважды.

Шаги воспроизведения

1. Подключиться к WebSocket
2. Разорвать соединение
3. Быстро переподключиться
4. Некоторые события приходят дважды

Причина

Race condition между старым и новым соединением

Исправление

| Дата | Действие |
|------|----------|
| 26 Ноябрь 2025 | Добавлена дедупликация по eventId |

---

BUG-RT-003: Отсутствует событие при изменении статуса на arrived

| Поле | Значение |
|------|----------|
| ID | BUG-RT-003 |
| Дата | 24 Ноябрь 2025 |
| Severity | High |
| Priority | P1 |
| Статус | Fixed |

Описание

Когда водитель меняет статус на arrived, пассажир не получает событие driver_arrived.

Шаги воспроизведения

1. Водитель принимает заказ
2. Водитель меняет статус на arrived
3. Пассажир не получает уведомление

Влияние

Пассажир не знает что водитель прибыл

Исправление

| Дата | Действие |
|------|----------|
| 27 Ноябрь 2025 | Добавлена публикация события driver_arrived |

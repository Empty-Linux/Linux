Описание сервиса

Realtime Service обеспечивает WebSocket соединения для real-time обновлений.

WebSocket соединения:
- Driver WebSocket - уведомления для водителей
- Passenger WebSocket - уведомления для пассажиров
- Admin WebSocket - мониторинг для администраторов

Основные события:
- Новый заказ для водителя
- Обновление статуса заказа
- Обновление локации водителя
- Системные уведомления

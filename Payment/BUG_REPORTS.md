BUG-PAY-001: Полный номер карты в логах

| Поле | Значение |
|------|----------|
| ID | BUG-PAY-001 |
| Дата | 14 декабрь 2025 |
| Severity | Critical |
| Priority | P1 |
| Статус | Fixed |

Описание

При ошибке токенизации полный номер карты записывается в логи.

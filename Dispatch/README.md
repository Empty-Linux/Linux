Описание сервиса

Order Dispatch Service отвечает за автоматический поиск и назначение водителей на заказы.

Основные функции:
- Получение заказов из Kafka
- Поиск ближайших водителей
- Отправка предложений водителям
- Обработка ответов (accept/reject/timeout)
- Назначение водителя на заказ

BUG-DSP-001: Предложение отправляется занятому водителю

| Поле | Значение |
|------|----------|
| ID | BUG-DSP-001 |
| Дата | 19 октября 2025 |
| Severity | High |
| Priority | P1 |
| Статус | Fixed |

Описание

При определенном timing предложение отправляется водителю, который только что принял другой заказ.

Шаги воспроизведения

1. Водитель A принимает заказ 1
2. Сразу создается заказ 2
3. Dispatch отправляет предложение водителю A
4. Водитель A уже занят

Причина

Кеш статуса водителя не инвалидируется мгновенно.

Исправление

| Дата | Действие |
|------|----------|
| 20 октября 2025 | Добавлена проверка статуса перед отправкой |

BUG-DSP-002: Бесконечный поиск при ошибке Location Service

| Поле | Значение |
|------|----------|
| ID | BUG-DSP-002 |
| Дата | 20 октября 2025 |
| Severity | Medium |
| Priority | P2 |
| Статус | Fixed |

Описание

Если Location Service недоступен, Dispatch продолжает retry бесконечно.

Ожидаемый результат

После 3 попыток должен публиковать order.no_drivers

Исправление

| Дата | Действие |
|------|----------|
| 21 октября 2025 | Добавлен circuit breaker и лимит retry |
